1. Создание объявления
TC-001: Успешное создание объявления
Шаги:
    Открыть страницу создания объявления по кнопке “Создать”
    Ввести корректные данные в обязательные поля (Название, цена, описание).
    Вставить URL изображения
    Нажать кнопку "Сохранить". 
Ожидаемый результат: Объявление успешно создается и отображается в списке объявлений.

TC-002: Создание объявления с незаполненными обязательными полями
Шаги:
    Открыть страницу создания объявления.
    Оставить одно или несколько обязательных полей пустыми.
    Нажать кнопку "Создать". 
Ожидаемый результат:
    Отображаются сообщения об ошибке с указанием обязательных полей.
    Объявление не создается.

TC-003: Создание объявления с некорректными данными
Шаги:
    Открыть страницу создания объявления.
    Ввести некорректные данные в одно или несколько полей (например, отрицательная цена, слишком длинное название, некорректный URL).
    Нажать кнопку "Создать". 
Ожидаемый результат:
    Отображаются сообщения об ошибках, соответствующие неверно заполненным полям.
    Объявление не создается. 

2. Редактирование объявления
TC-004: Успешное редактирование объявления
Предусловие: Создано объявление. 
Шаги:
    Открыть страницу списка объявлений.
    Выбрать и кликнуть объявление
    Нажать кнопку редактировать (Карандаш с листом).
    Внести изменения (URL, название, цену и описание).
    Нажать сохранить (Галочка). 
Ожидаемый результат: Изменения успешно сохраняются, объявление отображается с обновленными данными.

TC-005: Редактирование объявления с некорректными данными
Шаги:
    Открыть объявление для редактирования.
    Ввести некорректные данные (например, отрицательная цена, слишком длинное название, некорректный URL изображения).
    Нажать "Сохранить". 
Ожидаемый результат: 
    Отображается сообщения об ошибке.
    Данные не сохраняются.

3. Поиск объявлений
TC-006: Успешный поиск по существующему объявлению
Предусловие: В базе есть объявления. 
Шаги:
    Ввести корректное название существующего объявления в строку поиска.
    Нажать кнопку "Найти". 
Ожидаемый результат: В результатах поиска отображается нужное объявление.

TC-007: Поиск по несуществующему объявлению
Шаги:
    Ввести в строку поиска текст, которого нет в объявлениях.
    Нажать "Поиск". 
Ожидаемый результат: Объявления не отображаются.

TC-008: Фильтрация объявлений по параметрам
Предусловие: В базе есть объявления с разными значениями цены, количества просмотров и лайков. 
Шаги:
    Установить фильтр по одному из параметров (Цена, Просмотры, Лайки).
Ожидаемый результат: В результатах поиска отображаются объявления, соответствующие установленным параметрам.

TC-009: Сортировка объявлений
Предусловие: В базе есть объявления с разными значениями цены, количества просмотров и лайков. 
Шаги:
    Выбрать параметр сортировки (Цена, Просмотры, Лайки).
    Выбрать направление сортировки (по возрастанию или убыванию).
Ожидаемый результат: Объявления сортируются в соответствии с выбранным параметром и направлением.

TC-010: Изменение количества объявлений на странице
Предусловие: В базе есть объявления.
Шаги:
    Открыть страницу поиска.
    Выбрать количество объявлений, отображаемых на странице (5, 10, 15, 20, 25).
Ожидаемый результат: Отображается указанное количество объявлений на странице.
