Баг.1
Название: Цена сохраняется с отрицательным значением, возможен некорректный URL изображения

Предусловия: Открыта страница редактирования или создания товара
Шаги:
Ввести -100 в поле "Цена".
Ввести abc в поле "URL изображения".
Нажать "Сохранить".

Фактический результат: Цена сохранена, некорректный URL принят.
Ожидаемый результат: Цена должна быть >= 0, URL должен быть валидным.
Приоритет: High
